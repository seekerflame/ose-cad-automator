About

This is a static export of the CADAM schema library containing every module from the Open Source Ecology SH7 seed house and related assemblies. Each module was extracted from FreeCAD .fcstd files into a clean JSON schema, then re-compiled to .fcstd + .stl + human-readable build instructions + CSV bill of materials.

Select a module on the left to see it in 3D, read its BOM, and download the fabrication-ready STL.

Built with FreeCAD 1.0.2 + Python + three.js · Source: CADAM · Data: Open Source Ecology
